Livello — wersja Windows
Więcej na stronie progra24.pl

Aplikacja przeznaczona jest dla systemu Windows.

Wymagania:

- Windows 10 lub Windows 11
- system 64-bit
- .NET 8.0 Desktop Runtime x64
- Microsoft Edge WebView2 Runtime

Program zawiera własne środowisko PHP, dlatego nie ma potrzeby instalowania PHP osobno.

Livello działa lokalnie na komputerze użytkownika i nie wymaga instalacji.

Uruchomienie programu:

1. Pobierz i rozpakuj całe archiwum ZIP.
2. Nie uruchamiaj programu bezpośrednio z archiwum ZIP.
3. Uruchom plik Livello.exe.
4. Nie usuwaj katalogów php i www ani pozostałych plików znajdujących się w folderze programu.

Zaleca się rozpakowanie programu do katalogu, w którym użytkownik posiada pełne prawa zapisu, np.:
C:\Livello\
D:\Programy\Livello\
lub do własnego folderu użytkownika.

Unikaj umieszczania Livello w chronionych katalogach systemowych, takich jak:
C:\Program Files\
C:\Windows\

Dane, konfiguracja oraz kopie zapasowe są przetwarzane lokalnie na komputerze użytkownika.
